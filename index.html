為什麼需要 Transformer

「不受距離限制」指可見上下文內的直接連結；自迴歸生成仍逐 token 進行。

RNN / LSTM

訊息逐步傳遞

RNN 容易遺失長期關聯；LSTM 用閘門改善，但序列計算仍依賴前一步，平行化受限。

SELF-ATTENTION

遠方的詞，也能直接連上

任意 token 在可見上下文內直接建立關聯，不必逐步傳遞；訓練時序列運算可平行化。

① O(L²)

標準自注意力要比較所有詞的兩兩關係；長序列耗運算、耗記憶體。

② 很吃資料（指引寫「數據飢渴」）

大型模型往往需要大量資料；小資料有過擬合風險。

③ 無內建順序

注意力本身不會天生知道先後，要額外加入位置資訊。

Self-Attention 與 Q / K / V

讀書會比喻：先比對問題與專長名牌，再按相關程度整合同學講的內容。

Q

我想問什麼？

→
KEY · 索引

K

同學的專長名牌

把問題與專長名牌比對。

→
VALUE · 資訊

依相關程度整合內容。

Self-Attention：Q、K、V 都由同一輸入序列投影而來，讀出帶有上下文的表示。

Attention(Q,K,V) = softmax(QKᵀ / √d_k)V只要認得：√d_k 縮放分數，避免 softmax 過度飽和，幫助訓練穩定。

三塊積木，各管一件事

01 · 多視角

Multi-Head

多組 Q/K/V 投影到不同表示子空間，同時學不同注意力模式。

02 · 補順序

Positional Encoding

把位置資訊加入詞嵌入，讓模型能區分順序。

原始常見做法：固定正弦／餘弦；也可使用可學習的位置編碼。

讀書會比喻位置編碼像圍成一圈就沒有先後，所以每人發一張座位號碼牌。

03 · 深層可訓練

Residual + LayerNorm

Residual：給資訊與梯度跨層傳遞路徑。

LayerNorm：穩定特徵尺度，穩定深層訓練。

讀書會比喻Residual 像討論結論之外，原始講義也一起往下傳，不怕越討論越偏。

⚠️ Multi-Head 的主要優勢不是「減少參數」；補順序、穩定訓練也各有其他元件負責。

🎯 考試怎麼考

不同表示子空間 → Multi-Head（114-2 Q21）；順序 → 位置編碼；深層穩定 → Residual＋LayerNorm。

原始 Encoder–Decoder · 翻譯

BERT vs GPT：理解與生成

模型定位是判斷起點；此處比較原始 BERT 與典型 GPT。

比較面向BERTGPT
架構／方向Encoder-only／雙向上下文Decoder-only／單向自迴歸
預訓練任務MLM：隨機遮住幾個詞，讓模型猜回來
NSP：判斷兩句是否接續（原始 BERT）		根據已有前文，預測下一個 token
適合任務理解：分類、實體辨識、答案擷取生成：續寫、摘要、對話
生成差異雙向補詞目標，原始架構不以逐步續寫為主訓練方式直接對應「看前文、接下一詞」

⚠️ BERT 生成效果差，不能只怪「資料太少」或「模型太小」；先看架構與預訓練目標是否適合任務。

微調策略三選一

LoRA：跨科考點（科目三指引外，115-1 已考）

凍結 · 特徵萃取

Feature Extraction

凍結既有模型權重，取出特徵；只訓練後面新接的輸出層。

既有權重不更新
→ 115-1 Q42。

全面更新

Full Fine-tuning

更新整個預訓練模型的權重，以適應新任務。

可調整範圍大，訓練記憶體與成本通常較高。

低秩旁路

LoRA

凍結原權重，只訓練新增的低秩 A / B矩陣。

rank 高：適應能力較強、成本較高。
rank 低：較省資源、適應能力受限。

⚠️ Q35 的GPU 記憶體已近上限：公告選「降低 rank、套用更多層，保持可訓練參數總量」；不是一律加大 rank，實務上還是要實際測過品質和 GPU 記憶體用量。

🎯 考試怎麼考

凍結既有權重作特徵 → Feature Extraction；凍結＋訓練低秩旁路 → LoRA。

RAG：先找資料，再生成

RAG 提供外部依據，仍需要檢查檢索品質與回答是否忠於資料。

RAG：跨科考點（科目三指引外，115-1 已考）

01 · RETRIEVE

檢索相關資料

依問題找出知識庫片段。

→
02 · AUGMENT

放進 prompt

把問題與檢索內容一起提供。

→
03 · GENERATE

根據資料生成

讓答案有可參考的依據。

為什麼用？

減少幻覺風險；更新知識庫即可補新資訊，通常不必為每次知識更新重訓模型。

檢索階段怎麼改善？

檢查文件品質、切片與嵌入模型，評估語意匹配與相關性。

Hybrid Search 結合語意向量與關鍵字搜尋，補足單一檢索方式的侷限。
